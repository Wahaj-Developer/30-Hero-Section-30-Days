# 🎨 30 Days Hero Section Challenge

A collection of **30 unique hero sections** built over 30 days — one per day — using **React**, **Tailwind CSS**, and subtle CSS animations. Each section lives in its own directory as a self-contained `App.jsx` file, ready to drop into any React project.

---

## 📁 Project Structure

```
30-days-hero-challenge/
├── day-01/
│   └── App.jsx
├── day-02/
│   └── App.jsx
├── day-03/
│   └── App.jsx
│   ...
└── day-30/
    └── App.jsx
```

Each folder contains a single `App.jsx` — the complete hero section component with all styles and logic included.

## 🚀 Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Run Any Hero Section Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/wahajkhanahmed/30-days-hero-challenge.git
   cd 30-days-hero-challenge
   ```

2. **Scaffold a new React + Tailwind project** (if you don't have one)
   ```bash
   npm create vite@latest hero-preview -- --template react
   cd hero-preview
   npm install
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   ```

3. **Copy the day's component**
   ```bash
   cp ../day-01/App.jsx src/App.jsx
   ```

4. **Start the dev server**
   ```bash
   npm run dev
   ```

5. Open `http://localhost:5173` in your browser.

> ⚡ Repeat step 3 with any `day-XX/App.jsx` to preview a different section.
