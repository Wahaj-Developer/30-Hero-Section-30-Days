## 🚀 Getting Started

### Prerequisites
```bash
Node.js v18+
npm or yarn
```

### Quick Setup

```bash
# 1. Clone the repository
git clone https://github.com/wahajkhanahmed/30-days-hero-challenge.git
cd 30-days-hero-challenge

# 2. Create a new React + Tailwind project
npm create vite@latest hero-preview -- --template react
cd hero-preview
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 3. Copy a day's component
cp ../day-01/App.jsx src/App.jsx

# 4. Start dev server
npm run dev
```

> [!tip] Viewing Different Days
> To preview a different day's hero section, simply repeat step 3 with any `day-XX/App.jsx` file.
